Privacy

Last updated: {{ updated }}

{{ app_name }} has no email addresses, no names, and no passwords. Your account is anonymous. The service has no tracking, no ads, and no third-party analytics.

What the server stores

  • An anonymous account ID. The app gets a random ID and a secret token the first time it opens. The server keeps only a SHA-256 hash of the token.
  • Your devices. For each device: a device ID that the app makes, the platform, the device model, the OS version, the app version, and the push tokens that Apple gives the app.
  • Your API keys. For each key: a SHA-256 hash of the secret, your label, the first and last characters of the secret so that you can recognize it, the time of the last use, the name and version of the last MCP client that used it, and the last host name that an agent sent with it. The server cannot show a secret again.
  • Your tasks, questions, answers, and messages. The text that your agents and you write: task titles, descriptions, statuses, priorities, progress, and notes, the questions that an agent asks with their choices, the answers that you give, and the messages that you and your agents send.
  • The host name of the computer of an agent. The installer and the agent hooks send the short host name of the computer where an agent runs, so that the app can show where each agent runs. The server keeps the most recent host name with the API key, and puts the host name on each task that the agent makes and on each entry of the request log. The installer option --host sends a name of your choice as an alternative.
  • A request log for each API key. For each request that an agent makes with a key, the server keeps these items: the time, the tool or the route, the result (success, or an error code with a short error summary), the duration, the name and version of the client, and the host name. The app shows this log, so that you can see what went wrong. The log never has the text of a task, a question, an answer, a message, or a notification, and it never has a credential.
    • {% if uses_app_attest %}
  • An app attestation. When the app makes your account, it sends a proof from Apple's App Attest service that the request comes from the real app. The server keeps the key ID, the public key, and the counter of that proof with the account. They do not say who you are.
    • {% endif %}

What the server does not store

  • No name, no email address, no phone number, no contacts, no location.
  • No advertising identifiers and no tracking cookies. This site sets no cookies and loads nothing from other hosts.

Who gets your data

  • Apple. To send a notification or to update a Live Activity, the server sends the push token and the content of the notification, for example a task title, a question, and a key label, to the Apple Push Notification service.
  • The hosting provider. The server and its database run at a hosting provider, which keeps standard request logs. The server does not write a token or an API key to a log.

The operator does not sell data and does not share it with any other party.

Rate limits

To stop abuse, the server counts requests for each credential, and counts new accounts for each IP address. A counter for an IP address stays for two hours at most.

How long data stays

  • A task with the status done or cancelled is deleted {{ task_days }} days after its last change. The server keeps the newest {{ closed_tasks }} such tasks of a key.
  • A question that is answered, expired, or cancelled is deleted {{ question_days }} days after it closed.
  • A message to an agent is deleted {{ inbox_days }} days after it was sent, or {{ inbox_read_hours }} hours after the agent read it.
  • An entry of the request log is deleted {{ log_days }} days after the request. The server keeps the newest {{ log_entries }} entries of a key.
  • All other data stays until you delete it.

How to delete your data

Delete a task, a key, or the full account in the app. A deleted key stops at once. The server then removes its tasks, its questions, its messages, and its request log. A deleted account stops at once. The server then removes its devices, its keys, and all the data of those keys. You can also send DELETE /v1/account with your account token.
