Privacy

Last updated: {{ updated }}

{{ app_name }} has no email addresses, no names, and no passwords. Your account is anonymous. The service has no tracking, no ads, and no third-party analytics.

What the server stores

  • An anonymous account ID. The app gets a random ID and a secret token the first time it opens. The server keeps only a SHA-256 hash of the token.
  • Your devices. For each device: a device ID that the app makes, the platform, the device model, the OS version, the app version, and the push tokens that Apple gives the app.
  • Your API keys. For each key: a SHA-256 hash of the secret, your label, the first and last characters of the secret so that you can recognize it, the time of the last use, and the name and version of the last MCP client that used it. The server cannot show a secret again.
  • Your tasks, questions, and answers. The text that your agents and you write: task titles, descriptions, statuses, priorities, progress, and notes, the questions that an agent asks with their choices, and the answers that you give.
    • {% if uses_app_attest %}
  • An app attestation. When the app makes your account, it sends a proof from Apple's App Attest service that the request comes from the real app. The server keeps the key ID, the public key, and the counter of that proof with the account. They do not say who you are.
    • {% endif %}

What the server does not store

  • No name, no email address, no phone number, no contacts, no location.
  • No advertising identifiers and no tracking cookies. This site sets no cookies and loads nothing from other hosts.

Who gets your data

  • Apple. To send a notification or to update a Live Activity, the server sends the push token and the content of the notification, for example a task title, a question, and a key label, to the Apple Push Notification service.
  • The hosting provider. The server and its database run at a hosting provider, which keeps standard request logs. The server does not write a token or an API key to a log.

The operator does not sell data and does not share it with any other party.

Rate limits

To stop abuse, the server counts requests for each credential, and counts new accounts for each IP address. A counter for an IP address stays for two hours at most.

How long data stays

  • A task with the status done or cancelled is deleted {{ task_days }} days after its last change.
  • A question that is answered, expired, or cancelled is deleted {{ question_days }} days after it closed.
  • All other data stays until you delete it.

How to delete your data

Delete a task, a key, or the full account in the app. A deleted key takes all its tasks and questions with it. A deleted account takes its devices, keys, tasks, questions, and answers with it, immediately. You can also send DELETE /v1/account with your account token.
