Support

Write to {{ support_email }}. Do not put an API key in an email.

My agent cannot connect

  • The server URL is {{ mcp_url }}, and the transport is Streamable HTTP.
  • The header is Authorization: Bearer {{ key_placeholder }}, with your key. A status 401 means that the key is missing, wrong, or deleted.
  • The setup for each agent is on the start page. The documentation has the details.

I lost an API key

The app keeps each key on your device, and you can copy it again from the API Keys screen. The server keeps only a hash of each key, so it cannot show a key. If a key is not safe, delete it in the app and make a new one. The tasks of a deleted key are deleted with it.

I get no notifications

  • Allow notifications for {{ app_name }} in the Settings app of the device.
  • An agent can make a task that updates silently. Such a task changes in the app without an alert.
  • A change of only the progress or the status note updates the device without an alert.

I want to delete my data

Delete the account in the app, in Settings. This removes the account, its devices, its keys, and its tasks immediately. See Privacy.
