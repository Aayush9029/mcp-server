Privacy

No email. No password.

The app makes an anonymous account the first time it opens. The server stores no name and no email address. It has no tracking, no ads, and no third-party analytics.

  • One key for each agent

    Each agent has its own API key and sees only its own tasks. The server keeps a hash of the key, not the key.

  • Yours to delete

    Delete a task, a key, or the full account in the app. The server then removes its data.

  • Closed tasks expire

    The server deletes a task {{ task_days }} days after it is done or cancelled.

In short

From the agent to you.

An agent gets eleven tools. This is what they do on your side.

  1. The agent makes a task.

    You see it in the inbox on each device.

  2. The agent updates the status and the progress.

    You watch the task and its Live Activity change.

  3. The agent sends a notification.

    You get it on iPhone, iPad, and Apple Watch.

  4. The agent asks a question.

    You answer from the notification, the Live Activity, the app, or the watch.

  5. The agent reads its inbox.

    It gets your messages, your answers, and your changes to its tasks.
